# URAGAYA Storefront

A premium, responsive storefront concept for URAGAYA, a proposed Indian pickle brand rooted in Andhra Pradesh and intended for international customers.

## Stack

- Next.js App Router
- React and TypeScript
- Custom CSS
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current prototype features

- Responsive homepage and navigation
- Six proposed product cards
- Product search
- Add-to-bag interactions and quantity updates
- Provisional GBP product prices
- Currency selector UI
- Newsletter interaction placeholder
- Brand story, origin, recipe and shipping sections

## Important launch notes

This is a design-stage storefront, not a production commerce system. Product names, formulations, imagery, prices and claims must be reviewed before launch. Product photography currently uses remote Unsplash images as placeholders and should be replaced with approved URAGAYA assets.

The currency selector is visual only and does not convert prices. Checkout, customer accounts, payment processing, inventory, order fulfilment, shipping-rate calculation, newsletter storage, consent management and admin tools are not connected yet.

Before accepting orders, implement and test a secure commerce backend, payment provider, inventory and batch traceability, destination-specific shipping and tax logic, privacy and cookie controls, and country-specific food-import and labelling checks.
